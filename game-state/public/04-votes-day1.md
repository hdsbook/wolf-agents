# 第 1 天・投票紀錄

## 票型

| 投票者 | 投給 | 理由 |
|---|---|---|
| P1・阿狼 | **P3・小柴** | P3 用一個自己也搞錯的時間框架拆掉全場唯一的預言家地基；「洗金水給隊友」在被洗者不是狼時根本不成立。 |
| P2・小豆 | **P4・小四** | P4 整張牌押在「只有 P1 私訊我」這條獨家異常上，三人證實那是群發，地基斷了卻剛好產出洗金水加導票的雙重收益。 |
| P3・小柴 | **P1・阿狼** | （改票，原投 P4）P4 說「只有」還能用看不到別人信箱解釋，P1 對一個可驗證時間點的否認則是主動說謊。 |
| P4・小四 | **P3・小柴** | 我的「只有」講錯了我認，但地基斷的是修辭不是驗人；P3 是我跳完後第一個把我框進「悍跳洗隊友」並帶頭投放逐預言家的人。 |
| P5・老五 | **P8・阿灰** | 維持方向性判斷——P8 三項主張的共同效果都是讓好人今天資訊量最小化；也不願投進去製造平票、讓唯一的預言家牌在首日 PK 裡被順手打掉。 |
| P6・阿六 | **P4・小四** | 跟查驗結果走的前提是那張臉站得住；一個真預言家不會把首驗說成三個人一戳就破的獨佔理由，那不是記錯，是編造動機替一張臉補血。 |
| P7・小七 | **P1・阿狼** | 我是親歷者，P1 的時間點是假的——他在發牌與抿牌指示之前就私訊我了，卻用「我是開放後才發的」反打 P3 並替 P4 的金水護航。 |
| P8・阿灰 | **P4・小四** | P4 選在對我的圍剿正熱時才跳預言家，又把金水發給場上唯一自曝群發的 P1，等於用一張沒人能驗證的身份牌替既有票型加持。 |
| P9・老狐狸 | **P4・小四** | P4 自己就是做了同一件事的人——發牌前我依序收到 P1、P2、P3、P4 四人的自介；把自己也做過的行為描述成「只有他一個人做」再拿來當可信度地基，這動機是事後編的。 |

## 唱票結果

- **P4・小四：4 票** ← P2・小豆、P6・阿六、P8・阿灰、P9・老狐狸
- **P3・小柴：2 票** ← P1・阿狼、P4・小四
- **P1・阿狼：2 票** ← P3・小柴、P7・小七
- **P8・阿灰：1 票** ← P5・老五

票數總和 9，等於存活人數 9，**無漏票**。

## 裁決

**P4・小四 以 4 票最高票出局，未達平票，不進入 PK。**

- 出局者身份**不公布**，依規則保密。
- 出局者非獵人，無開槍程序。
- 勝負條件檢查：**未達成**，遊戲繼續。
