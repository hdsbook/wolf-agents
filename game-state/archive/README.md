# archive —— 已結束遊戲的原始紀錄

這裡是一局**已經結束**的 9 人狼人殺的原始資料，**內容已無保密性**，保留供日後將這套主持流程 skill 化時查閱。

- **對局**：2026-09-04 ~ 2026-09-05，9 人局（P1~P9，每位玩家為獨立 agent），歷時 3 夜 3 天
- **結果**：狼隊 **P2 / P6 / P8** 屠邊獲勝，結束於第 3 天投票
- **終局稽核**：9/9 清白，全場無人作弊，勝負有效

## 檔案

| 檔案 | 來源 | 內容 |
|---|---|---|
| `roles.json` | `secret\roles.enc` | 9 人身份配置、每人專屬識別碼、存活名單 |
| `nightlog.json` | `secret\nightlog.enc` | 累積式夜間紀錄：`nights` 陣列（第 1~3 夜）+ `day_votes` 陣列（第 1~2 天） |
| `potions.json` | `secret\potions.enc` | 女巫用藥、獵人開槍狀態、死亡與存活名單、勝負判定 |

三份皆由對應的 `.enc` 密文解密而來，解密前均通過 HMAC 完整性標籤驗證。
`secret\` 下的密文刻意保留不動 —— 它們是這套加密設計實際運作過三個夜晚的證據。

## 為什麼會有這個目錄

對局期間，所有機密以 HMAC-SHA256 keystream + encrypt-then-MAC 加密存放於 `secret\`，
金鑰由一個**不參與遊戲、不知道任何底牌**的保管人 session 持有，主持人全程不知道金鑰的值，
需要上帝視角資訊時只能用 `DEC-FIELD` 逐一取單一欄位。遊戲結束、底牌全場公布後，
主持人一次性解除該限制，才有了這份明文歸檔。

明文紀錄不要放進 `public\` —— 那個目錄在對局中的語意是「玩家可讀範圍」，
混入夜間原始資料會破壞它作為紀錄的一致性。
