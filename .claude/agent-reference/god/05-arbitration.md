# 工作流程：裁決手冊

**情境**：遇到需要你做判斷的規則情境。

**原則：所有裁決標準都寫在公開的 `.claude/rules/flow.md`，玩家讀得到。你照章執行，不臨場加碼。**

---

## 狼隊意見不一致

**不需要裁決 —— 隊長拍板就是結論。**

```
隊友暗號（具名原文轉給隊長）
└─ 隊長決定 → 直接成立，不需要誰同意
   ├─ 隊長逾時 → 重發一次
   │  └─ 再逾時 → 接班順位第一位代為決定
   └─ 全員逾時 → 你隨機裁決刀人目標
```

**空刀不成立。** 每晚必定產生一個目標。非隊長逾時視為棄權，不影響隊長的決定。

> 以前這裡是「匿名彙整再一輪取多數決」。那個機制的價值在收斂，
> 但它同時擋住了分工 —— 匿名之下沒人能說「你去悍跳、我站你」。
> 隊長制把收斂交給一個人，換回了狼隊在夜裡分工的能力。

> **隊長沒指派分工不是爭議，不要裁決它。** 那是他的選擇，補問等於暗示他該指派。

---

## 白天投票平票

```
唱票
├─ 有唯一最高票 → 出局
└─ 平票
   └─ PK：平票者各再發言一次 → 其餘玩家重投（平票者不投）
      ├─ 有唯一最高票 → 出局
      └─ 再度平票 → 本輪流局，無人出局
```

**流局是真實且代價高昂的結果。不要為了「有個結論」而擅自加碼裁決。**

> 上一局實際發生過一次 PK 二度平票流局，好人因此白讓一輪 —— 那是決定勝負的三個瞬間之一。

## 獵人開槍

| 死因 | 能否開槍 |
|---|---|
| 被狼人刀死 | ✅ |
| 被投票放逐 | ✅ |
| **被女巫毒死** | ❌ |

**時機**：獵人死亡時**先單獨詢問開槍對象，結算後才公布完整死亡名單**。不要先公布再補槍。

獵人可在生前預先宣告槍口並隨時更新；那是他的戰術選擇，你只負責執行他死亡當下的最新宣告。

---

## 逾時

**一律先重發一次澄清訊息。** 再無有效回應才套用預設：

| 角色 | 預設 |
|---|---|
| 狼人 | 棄權，不計入多數決 |
| 預言家 | 空過，本夜無查驗 |
| 女巫 | 不用藥 |
| 投票 | 棄票 |
| 發言 | 跳過，並在逐字稿中註明 |

## 勝負判定

```python
if not wolves_alive:                          好人勝
elif not gods_alive or not villagers_alive:   狼人屠邊勝
else:                                         繼續
```

**用程式算，不要心算。** 每次天亮結算後、每次投票結算後各檢查一次。

**屠邊是最容易漏掉的結局** —— 上一局遊戲就是在投出最後一名平民的那一刻結束的，而全場沒有人算到。

---

## 玩家對規則有疑義

1. 引用 `.claude/rules/` 的**原文**回覆，不要改寫或加註
2. 若規則確實沒寫清楚 → 當場裁定、**向全體公告你的裁定**、並補進規則檔
3. **不要對同一情境給出兩種裁定** —— 前後不一致比裁錯更傷

---

## 玩家指控你違反中立性

這是他們的權利，寫在公開的 `god-neutrality.md` 裡。

1. **先查證**，不要辯解
2. 構成違規 → 承認、在該階段公開紀錄中記載、修正模板
3. 不構成 → 說明為何不構成，並引用契約條文

**指出裁判的錯誤不影響玩家的遊戲權益。** 上一局玩家兩次指出主持方的問題，兩次都是他們對。
