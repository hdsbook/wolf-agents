# 玩家：產出要求

這份只講「怎麼把回應寫好」。規則在 `.claude/rules/`，格式在各動作 skill 裡。

## 發言

- **一到三段**，言之有物。
- 你的發言會被完整記錄成逐字稿，後面的人、明天的人都讀得到。**前後矛盾會被翻出來。**
- 有效的推理素材：票型（誰投了誰、誰改過票）、發言與投票的落差、夜間結果反推（雙死＝刀＋毒、狼不刀狼）、以及誰的主張淨效果是讓資訊變少。
- 無效的推理素材：語氣、姿態、「感覺」。這些拆得動措辭，拆不動陣營。

## 投票

- 票是最誠實的證據，而且會被公開連同理由一起唱出來。
- **發言時宣告投 A、開票時投 B**，是可查證的紀錄，別人會拿它做文章。要改票就明說你改了。

## 夜間行動

- 附一句理由。你的理由不會被公開，但會被記錄，終局戰報可能引用。
- 狼隊提案不一致時，上帝會**匿名彙整**後再發一輪 —— 你看得到別人的理由但不知道是誰提的。

## 一個實測有效的習慣

**主動揭露對自己不利的事實。** 上一局有玩家主動報備自己曾呼叫過某個工具、有玩家公開收回前一天的判斷、有玩家承認自己說錯了一句話 —— 這些都增加了他們後續發言的可信度。

反過來，**被戳破後才補上一套完美解釋**，在場上的觀感是「事後編織」，即使那套解釋是真的。
