# 工作流程：產出報表

## 什麼時候跑

上帝在**天亮結算後**與**投票結算後**會通知你。人類觀戰者也可以隨時直接要求。
接到通知就跑完整流程，不要只更新一部分 —— 部分更新的報表比過期的報表更難察覺錯誤。

---

## 步驟

### 1. 先驗，再畫

**永遠先跑 `workflow-verify.md` 的檢查。** 資料不一致時畫出來的圖只會把錯誤放大成看起來很有說服力的樣子。

檢查沒過 → **先通報上帝，等他修正，不要自己畫**。

### 2. 讀資料

| 來源 | 取什麼 |
|---|---|
| `public/00-players.md` | 座位與暱稱 |
| `public/02-status.md` | 天數、階段、存活名單、下一步 |
| `public/01-timeline.md` | 每階段的公開事件 |
| `public/03-speeches-dayN.md` | 發言逐字稿（**全文，不摘要**） |
| `public/04-votes-dayN.md` | 票型與投票理由 |
| `secret/roles.json` | 底牌（**只進劇透版**） |
| `secret/nightlog.json` | 每夜刀／查驗／用藥（**只進劇透版**） |
| `secret/potions.json` | 藥水與開槍狀態、勝負判定（**只進劇透版**） |

### 3. 產出兩份

先產公開版，再**以公開版為基礎**加上劇透層產劇透版。

> 順序很重要：反過來做（從劇透版刪掉機密）是**黑名單思維**，
> 漏掉一處就洩漏。從公開版往上加是**白名單思維**，漏掉一處只是少了資訊。
> 這條與 `agent-memory/shared/lessons.md` 的 L3 是同一個道理。

### 4. 公開版跑防劇透掃描（**不可略過**）

```
掃描規則：P[1-9] 前後 14 個字元內，出現以下任一字樣即為命中
          狼人／預言家／女巫／獵人／平民／村民／查驗／毒／解藥
必須 0 命中
```

命中 → **不要交付**，找出來源修掉再掃一次。腳本會自己擋下，不會產生半成品。

> 上一局上帝就是因為訊息模板的範例寫了真實座位號，把一個身份洩漏給了純觀戰的人類。
> 掃描是機械化的，人的注意力不是。

### 掃描範圍：只查你生成的字

**逐字取自公開檔的內容一律排除在掃描之外。**

玩家的發言裡本來就充滿「我跳預言家」「P8 是狼」這類句子，公開發言檔的標題也可能
寫著「P4・小四【跳預言家】」—— 那些是**上帝已經公開、玩家都讀得到的原文**。
把它們納入掃描只會得到一堆假陽性，然後你就會開始習慣性忽略掃描結果，
**那才是真正的危險**。

腳本用 `<!--QUOTE-->` 標記包住所有逐字引用區（發言內文、發言標題、座位暱稱、
投票理由、唱票結果），掃描時整段剔除。

判準一句話：**這段字是你生成的，還是從公開檔原樣抄來的？** 只有前者要掃。

### 5. 回報

告訴上帝：兩份都已更新、目前天數與階段、以及**檢查是否全過**。
若有檢查未過，這裡要再講一次。

## 兩份報表各放什麼

### 公開版 `game-state/report/index.html`

| 區塊 | 內容 |
|---|---|
| 頂部狀態列 | 第幾天／第幾階段／存活人數／下一步 |
| 座位圖 | 9 個座位，存活與死亡以視覺區分。**不顯示死因，不顯示身份** |
| 時間軸 | 逐日展開：夜晚結果（只有「誰死了」）、投票結果 |
| 發言 | 依天分頁，每人一段，**逐字全文**，可摺疊 |
| 票型矩陣 | 誰投誰的表格，附投票理由原文 |

**公開版的資訊界線＝玩家讀得到的界線。** 判準很簡單：
**如果一個玩家不該知道，它就不該出現在公開版。**

### 劇透版 `game-state/secret/report-spoiler.html`

在公開版之上疊加：

| 區塊 | 內容 |
|---|---|
| 座位圖 | 每個座位標上真實身份，狼人與好人以顏色區分 |
| 時間軸 | 補上死因：被刀／被毒／被投票／被獵人帶走 |
| 夜間面板 | 每夜的刀人目標與提案分歧、查驗對象與結果、用藥決定 |
| 發言對照 | 每段發言旁標註發言者的真實陣營 —— **這是這份報表最有價值的一欄** |
| 票型矩陣 | 票格依投票者與被投者的真實陣營著色，一眼看出誰在幫誰 |

## 腳本在哪

`.claude/skills/reporter-build/render.py`

它是確定性的：同樣的資料永遠產生同樣的報表。**版面要改就改腳本**，
不要這一次手動補幾行 —— 手動補的東西下一次就消失了，而你不會發現。

## 技術要求

- **單一自足 HTML 檔**：CSS 與 JS 全部內嵌，**零外部相依**。
  這台機器上的瀏覽器可能沒有網路，CDN 連不到就整份版面壞掉。
- **深色／淺色都要能看**：用 `prefers-color-scheme`，並且明確指定 `body` 背景色。
- **寬內容自己捲**：票型矩陣與逐字稿放進 `overflow-x: auto` 的容器，頁面本身不得橫向捲動。
- **兩份用同一個樣板**，劇透層以旗標控制。樣板分家會漂移。
