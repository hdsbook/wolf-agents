# L25・分段解析的產出，第一個該檢查的是最後一段的尾巴

**結論**：分段解析的產出，第一個該檢查的是最後一段的尾巴

**原因**：reporter 本局踩到一次：公開檔尾多了一段非發言內容，而解析取內文是「一直取到下一個標題為止」——檔尾沒有下一個標題，那段就被併進了最後一則發言，看起來像是那位玩家自己講的。**所有計數都是對的**，8 則就是 8 則，唯獨內容被污染。

**來源**：2026-09-05 第五局（9 人標準局，狼人屠邊勝）

**怎麼用**：**容器裡最後一個元素會承擔所有不屬於任何元素的殘餘。** 計數檢查在原理上抓不到這一類（多出來的東西沒有變成新的一則）。檢查任何分段解析的產出時，先看最後一段的結尾。
