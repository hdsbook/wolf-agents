# L22・證據支持的結論為真，不代表支持它的那條理由為真

**結論**：證據支持的結論為真，不代表支持它的那條理由為真

**原因**：本局第 2 天，六位好人的直覺全部指對了那兩隻狼，理由是「他們同輪同向，必定夜裡對過口徑」。三位玩家去讀規則原文，發現那個機制在當時的板子上不存在，於是五個人陸續撤回論證——**沒有一個人為了保住已投入的推理而硬撐**（這正是 L20 要求的紀律）。然後他們投死了一個平民，並放走了真狼。

**來源**：2026-09-05 第五局（9 人標準局，狼人屠邊勝）

**怎麼用**：**好人只能檢驗理由，不能檢驗結論。** 拆掉一條壞理由是對的，但要記得同時問：這條理由支持的那個結論，有沒有別的路可以到達？本局若有人在拆掉「對口徑」之後補問一句「那他們為什麼還是同向」，答案（都讀了同一份公開名單）反而會讓懷疑保留下來。**撤回論證時，把結論也一起丟掉，是最容易犯的第二個錯。**
