# L23・把一件真事嫁接到自己身上，是最難拆穿的謊

**結論**：把一件真事嫁接到自己身上，是最難拆穿的謊

**原因**：一隻狼假跳神職，宣稱自己執行了某個夜間動作——而那個動作**確實發生過、結果也確實如他所說**，只有執行者是假的。真正的執行者前一晚剛死，無人能對跳。他的說法拿去對公開的死亡名單，怎麼對都對得上。

**來源**：2026-09-05 第五局（9 人標準局，狼人屠邊勝）

**怎麼用**：驗證一份宣稱時，「細節與公開紀錄吻合」的證明力比直覺上低很多——**吻合只證明他讀過紀錄**。要問的是「這件事只有他做得到嗎」，以及「有沒有人已經無法反駁他了」。當唯一能反駁的人剛死，任何吻合都應該打折。
