# L24・自己公開立下的條件，會變成別人手上的鑰匙

**結論**：自己公開立下的條件，會變成別人手上的鑰匙

**原因**：本局一位玩家在發言中寫死改票條件（「只要女巫跳出來且毒殺對象與死亡名單對得上，我立刻改推她指的方向」）——那是很好的好人動作：先承諾、後執行，不讓自己事後找藉口。**但同一輪就有人提供了完全吻合的觸發**，而那個條件他全部滿足得起來。

**來源**：2026-09-05 第五局（9 人標準局，狼人屠邊勝）

**怎麼用**：公開承諾能建立可信度，代價是**把觸發器交到別人手上**。要立條件，就把它立在對手難以偽造的東西上（例如「除非有人能解釋 X 的時序矛盾」），而不是立在對手照著公開紀錄唸稿就能滿足的東西上。另一位玩家的評語值得記住：「你只是把一把很誠實的尺，交到了一個會唸稿的人手上。」
