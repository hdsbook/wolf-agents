# 跨角色教訓（追加式）

每則一檔，格式：**結論** → **原因** → **來源** → **怎麼用**。
**不得記載任何一局的底牌或當局狀態。** 這個目錄玩家在檔案系統層面讀得到。

**新增教訓**：在 `lessons/` 新增一檔，四欄格式（結論／原因／來源／怎麼用），並在本索引加一行。

---


## 2026-09-04 首局（9 人標準局，3 夜 3 天）

- [L1・先問「這份資訊屬於哪一層」](lessons/L1-先問這份資訊屬於哪一.md) — 判斷一個保護機制好不好，看它保護的範圍是否涵蓋真正的攻擊面，而不是看它的技術強度。
- [L2・持久記憶不要寫進共用目錄](lessons/L2-持久記憶不要寫進共用.md) — 任何角色的私有筆記都放到共用目錄之外。
- [L3・公開檔採白名單思維](lessons/L3-公開檔採白名單思維.md) — 誘餌與浮水印一旦公開就完全失效；寫出 transcript 路徑等於教人作弊。
- [L9・範例一律用佔位符](lessons/L9-範例一律用佔位符.md) — 首局曾因訊息模板範例寫成真實座位號而洩漏一個身份。
- [L10・說謊與作弊的界線要公開寫清楚](lessons/L10-說謊與作弊的界線要公.md) — 這條不講清楚，agent 會因為誠實傾向而不敢正常玩狼人殺，整局會變得很平。
- [L11・公開宣告稽核](lessons/L11-公開宣告稽核.md) — 把稽核範圍與可追溯性寫進公開守則。
- [L12・session 重啟偵測要主動](lessons/L12-session重啟偵.md) — 每階段開始前用 ListAgents 比對各 session 的 ref 與開局基準，變動就要求重跑 /ur。
- [L18・撤回的成本不是均等分配的](lessons/L18-撤回的成本不是均等分.md) — 評價某人「不肯認錯」之前，先算他撤回要付多少。
- [L19・「必敗」不等於「為假」](lessons/L19-必敗不等於為假.md) — 推理到「這條路必敗所以走另一條」時停一下 —— 你是在判斷哪個世界為真，還是在選擇一個你需要為真的世界？
- [L20・成本與正確性無關](lessons/L20-成本與正確性無關.md) — 一段愈來愈漂亮的論證，很可能只是因為它愈來愈貴。

## 2026-09-05 第四局

- [L21・你回覆的內容會進到對方的 prompt，並可能觸發對方的 hook](lessons/L21-你回覆的內容會進到對.md) — 回覆任何人時，一律用文字敘述指涉指令（「角色認領先前已完成」），不要寫出斜線開頭的字串。

## 2026-09-05 第五局（9 人標準局，狼人屠邊勝）

- [L22・證據支持的結論為真，不代表支持它的那條理由為真](lessons/L22-證據支持的結論為真不.md) — 好人只能檢驗理由，不能檢驗結論。
- [L23・把一件真事嫁接到自己身上，是最難拆穿的謊](lessons/L23-把一件真事嫁接到自己.md) — 驗證一份宣稱時，「細節與公開紀錄吻合」的證明力比直覺上低很多——吻合只證明他讀過紀錄。
- [L24・自己公開立下的條件，會變成別人手上的鑰匙](lessons/L24-自己公開立下的條件會.md) — 公開承諾能建立可信度，代價是把觸發器交到別人手上。
- [L25・分段解析的產出，第一個該檢查的是最後一段的尾巴](lessons/L25-分段解析的產出第一個.md) — 容器裡最後一個元素會承擔所有不屬於任何元素的殘餘。
- [L26・檢查自動產生的東西，要同時做兩種相反的搜尋](lessons/L26-檢查自動產生的東西要.md) — reporter 由此發展出逐塊確認五問——這一塊在不在／有沒有不像人話的東西／欄位是不是不該地空著／數量對不對／最後一段的尾巴乾不乾淨。
- [L27・用「鍵在不在」決定顯示，不要用「值真不真」](lessons/L27-用鍵在不在決定顯示不.md) — 判斷「這個概念在這一夜存不存在」用鍵的有無；判斷「他做了什麼」才用值。
