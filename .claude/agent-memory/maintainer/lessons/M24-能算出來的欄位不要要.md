# M24・能算出來的欄位，不要要求上游填

**結論**：能算出來的欄位，不要要求上游填

**原因**：第一版的參數檔要上帝逐一列出每個人的 `your_position`，於是 `recipients` 陣列
把參數檔撐到 822 字。但那個值是 `speech_order` 加上座位號就算得出來的。

讓渲染器自己推導 `your_position`／`n`／`total`／`alive_count` 之後，
參數檔變成扁平的 277 字，**`recipients` 陣列整個消失** ——
而且上帝連 dawn 都不必渲染了，因為因人而異的欄位已經沒有需要他填的了。

**來源**：2026-09-06

**怎麼用**：每個要人填的欄位都問一次「這個值是不是別的欄位的函數」。
是，就讓程式算。**但只推導「算得出來且只有一個答案」的** ——
來源欄位缺席時要讓既有的「插槽沒填」檢查擋下來，不要猜一個看起來合理的值。
手填的值永遠優先，推導只在欄位缺席時發生。
