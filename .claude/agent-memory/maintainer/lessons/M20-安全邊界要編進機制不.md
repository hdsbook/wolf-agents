# M20・安全邊界要編進機制，不要只寫在文件裡

**結論**：安全邊界要編進機制，不要只寫在文件裡

**原因**：可落檔的清單同時存在兩處：`god-dispatch/SKILL.md` 的表格（給人看）
與 `render.py` 的 `FILE_OK`（給機器擋）。**後者才是保證。**
上帝只要對含機密的 action 下 `--out`，腳本就拒絕、一個檔都不產生 ——
不必依賴他有沒有讀到表格、有沒有讀懂。

這跟這個專案既有的做法是同一路：路徑保護不靠自律，靠 hook 實際攔截。

**來源**：2026-09-06

**怎麼用**：每寫一條「不可以做 X」的規則，問一句**「誰會擋住它」**。
答案是「讀到的人自己」就代表它只是文件；能指出一個會回傳錯誤的地方，它才是機制。
文件那份不是多餘的 —— 它解釋為什麼 —— 但兩份要同時存在，而且要說清楚哪一份是權威。
