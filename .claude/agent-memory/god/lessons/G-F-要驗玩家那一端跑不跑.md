# G-F・要驗玩家那一端跑不跑得動，就得真的找玩家跑

**結論**：要驗玩家那一端跑不跑得動，就得真的找玩家跑

**原因**：模板在我這裡渲染得出來，不代表玩家跑得動 —— hook 認的是 session id，權限不同。
本局改完傳遞方式後找一位玩家（不是全部九位）用假資料實測三則，他回報的四項裡
有兩項是我自己看不出來的：`{{leader}}` 與 `{{leader_note}}` 之間漏了換行、
訊息缺逾時判定與「別人的自介去哪讀」。

**來源**：2026-09-06

**怎麼用**：改動任何玩家端的機制後，**找一位**玩家用假資料實測，並要求他回報
「哪裡看不懂、哪裡資訊不足」。找一位就夠了 —— 九位跑同一件事只會拿到九份相同結果，
卻要九倍的來回。假資料是關鍵：那讓他可以把輸出原文貼回來給你看。
