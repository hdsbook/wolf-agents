# G-D・訊息裡「只有一小撮是機密」時，不要整則直送

**結論**：訊息裡「只有一小撮是機密」時，不要整則直送

**原因**：發牌訊息 1953 字，真正機密的只有 41～130 字（角色、隊友、識別碼），其餘全是玩家
在角色認領時就讀過的公開內容。我卻把整則當成機密訊息，自己渲染完再逐字貼九次 ——
同一份內容產出兩遍、九個回合，那是開局最慢的一步的全部成因。

**來源**：2026-09-06

**怎麼用**：要直送一則訊息之前，先問「這裡面哪幾個字是玩家不知道的」。
只有那幾個字需要經過你；其餘一律讓他自己去讀或自己去渲染。
`render.py --params` 同時吃檔案路徑與 JSON 字串，所以機密訊息也能交給玩家渲染 ——
把 JSON 放進點對點私訊即可，不必落檔。
