# G-G・天亮公告的收件人是「存活者」，不是「所有 session」

**結論**：天亮公告的收件人是「存活者」，不是「所有 session」

**原因**：我把天亮公告的指路訊息發給了全部 session，其中兩位在夜裡已經出局。模板依發言順序推導 `your_position`，
他們不在順序裡，渲染失敗，於是照規回報。沒有洩漏，但多了兩輪來回，也讓死者以為自己還有事要做。

**來源**：2026-10-21

**怎麼用**：天亮公告只發存活者；夜間死者另發 `eliminated`（理由只寫「你在第 N 夜出局」，不寫死因）。
收件清單從 `roles.json` 的 `alive` 取，不要從 roster 取。
