# 上帝的教訓（追加式）

每則格式：**教訓** → **怎麼用** → 來源局次。
**絕不記載任何一局的底牌或當局狀態。**

---



## 2026-09-06

### G-A・存活名單有三處，收尾時逐一點名
出局結算後我更新了 `potions.json` 與 `02-status.md`，漏掉 `roles.json` 的 `alive`，
reporter 當場擋下報表（它寧可不產，也不產一份「死者還活著」的畫面）。
**怎麼用**：投票／夜間結算的收尾清單裡，把「三處存活名單」寫成三個**檔名**逐一勾，
不要寫成一句「更新狀態檔」—— 抽象的那句話會讓你以為兩個就是全部。

### G-B・一條驗不到東西的檢查，比沒有檢查危險
reporter 的票數統計正則一度對不上表格格式，跑出 0 票卻回報「通過」。它主動說出來。
**怎麼用**：任何自動檢查回報通過時，順手問一句「它這次實際讀到了幾筆」。
通過與「有東西被驗到」是兩件事；只有後者存在時，前者才有意義。

### G-C・派下一位發言前，等的是「本人的落檔回報」，不是併檔端的回報
第 2 天我看到併檔端說「某位的檔已在 inbox」就派了下一位，而那位本人的落檔回報還沒到。
下一位列資料夾時檔案尚未寫完，必讀清單與現場對不上，他依規定停下等我。
**怎麼用**：必讀清單的權威來源只有一個 —— **玩家本人回報「已落檔」**。
第三方看到檔案存在不等於寫入完成，兩者之間有真實的時間差。

### G-D・訊息裡「只有一小撮是機密」時，不要整則直送
發牌訊息 1953 字，真正機密的只有 41～130 字（角色、隊友、識別碼），其餘全是玩家
在角色認領時就讀過的公開內容。我卻把整則當成機密訊息，自己渲染完再逐字貼九次 ——
同一份內容產出兩遍、九個回合，那是開局最慢的一步的全部成因。
**怎麼用**：要直送一則訊息之前，先問「這裡面哪幾個字是玩家不知道的」。
只有那幾個字需要經過你；其餘一律讓他自己去讀或自己去渲染。
`render.py --params` 同時吃檔案路徑與 JSON 字串，所以機密訊息也能交給玩家渲染 ——
把 JSON 放進點對點私訊即可，不必落檔。

### G-E・文件說「腳本會算」，要真的去驗它算不算
`god-dispatch` 明寫 `alive_count` 由腳本從 `alive_list` 推導，實際上腳本只在
「你沒填」時才算；填錯了它照印，於是 `alive_count: 5` 配九個座位會印出
「存活 5 人：P1…P9」，沒有任何人會發現。
**怎麼用**：這是 G-B 的同一個形狀 —— 一條驗不到東西的檢查。驗自動推導的欄位，
**要故意填一個錯的值進去看它擋不擋**，不要填對的值然後看到對的結果就放心。
（這個測法是玩家提的，不是我想到的。）

### G-F・要驗玩家那一端跑不跑得動，就得真的找玩家跑
模板在我這裡渲染得出來，不代表玩家跑得動 —— hook 認的是 session id，權限不同。
本局改完傳遞方式後找一位玩家（不是全部九位）用假資料實測三則，他回報的四項裡
有兩項是我自己看不出來的：`{{leader}}` 與 `{{leader_note}}` 之間漏了換行、
訊息缺逾時判定與「別人的自介去哪讀」。
**怎麼用**：改動任何玩家端的機制後，**找一位**玩家用假資料實測，並要求他回報
「哪裡看不懂、哪裡資訊不足」。找一位就夠了 —— 九位跑同一件事只會拿到九份相同結果，
卻要九倍的來回。假資料是關鍵：那讓他可以把輸出原文貼回來給你看。

## 2026-10-21

### G-G・天亮公告的收件人是「存活者」，不是「所有 session」
我把天亮公告的指路訊息發給了全部 session，其中兩位在夜裡已經出局。模板依發言順序推導 `your_position`，
他們不在順序裡，渲染失敗，於是照規回報。沒有洩漏，但多了兩輪來回，也讓死者以為自己還有事要做。
**怎麼用**：天亮公告只發存活者；夜間死者另發 `eliminated`（理由只寫「你在第 N 夜出局」，不寫死因）。
收件清單從 `roles.json` 的 `alive` 取，不要從 roster 取。

### G-H・投票回覆裡的獵人槍口宣告是機密，唱票時要先剝掉
獵人在投票格式裡另起一行更新槍口。唱票要公開「所有理由原文」，但那一行一公開就等於翻了獵人的牌。
**怎麼用**：解析投票時只取 `投票：` 與 `理由：` 兩行進公開票型；`槍口：` 寫進 `nightlog.json` 的 `hunter_declaration`。

### G-I・稽核掃「收件人非上帝」時，要認得上帝的所有別名
玩家報到時可能用 session 名稱、ref 或 `God` 試送，掃描只認 `uds:` 會誤報。
**怎麼用**：開局記下上帝 session 的名稱與 ref，命中時先看內容是否為報到或對上帝的回覆再下結論。
