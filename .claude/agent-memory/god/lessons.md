## 2026-09-06

### G-A・存活名單有三處，收尾時逐一點名
出局結算後我更新了 `potions.json` 與 `02-status.md`，漏掉 `roles.json` 的 `alive`，
reporter 當場擋下報表（它寧可不產，也不產一份「死者還活著」的畫面）。
**怎麼用**：投票／夜間結算的收尾清單裡，把「三處存活名單」寫成三個**檔名**逐一勾，
不要寫成一句「更新狀態檔」—— 抽象的那句話會讓你以為兩個就是全部。

### G-B・一條驗不到東西的檢查，比沒有檢查危險
reporter 的票數統計正則一度對不上表格格式，跑出 0 票卻回報「通過」。它主動說出來。
**怎麼用**：任何自動檢查回報通過時，順手問一句「它這次實際讀到了幾筆」。
通過與「有東西被驗到」是兩件事；只有後者存在時，前者才有意義。
