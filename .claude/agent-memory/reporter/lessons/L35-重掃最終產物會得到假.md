# L35・重掃最終產物會得到假陽性，因為剔除標記已經被移除了

**結論**：重掃最終產物會得到假陽性，因為剔除標記已經被移除了

**原因**：防劇透掃描在 render 內部跑，順序是「剔除 QUOTE 引用區 → 掃描 → 移除標記 → 寫檔」。
所以**最終 HTML 裡看不到 QUOTE 標記是正常的**，而拿最終檔重掃一次會把玩家發言
全部算成命中（本局重掃得到 15 筆，全是假陽性）。

**來源**：（原文未記）

**怎麼用**：要獨立驗證掃描有沒有作用，做兩件事而不是重掃：
一、**牙齒測試** —— 把劇透版餵進同一支掃描函式，應該大量命中；回傳 0 才是壞了。
二、**逐筆溯源** —— 若真要檢查公開版，把每筆疑似命中拿去比對玩家原文與票型檔，
能溯源到公開文字的就是假陽性，溯源不到的才是真洩漏。

基準表補記：第 1 天投票結算 nights=1、day_votes=1。
