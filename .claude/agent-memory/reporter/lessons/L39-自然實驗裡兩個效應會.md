# L39・自然實驗裡兩個效應會纏在一起，指出混淆因子是你的職責

**結論**：自然實驗裡兩個效應會纏在一起，指出混淆因子是你的職責

**原因**：本局出現一個現成的對照：規範提醒在第 4 位發言者才送出，於是前三位成了對照組、後六位成了實驗組。
字數確實下降，看起來提醒有效。**但實驗組裡唯二守住上限的是最後兩位，而他們同時也是聽過最多人發言的兩位**——
「提醒有效」與「後置位更知道該講什麼所以更精簡」在單日資料上完全分不開。

**來源**：（原文未記）

**怎麼用**：你是唯一同時看得到全部資料與全部時序的人，所以混淆因子由你指出。
指出它不會削弱結論，它讓結論知道自己該等哪一批資料才成立
（本例：等順序重抽、全員都已收到提醒的下一天，位置效應與提醒效應就分開了）。
**在別人準備拿你的數字下結論之前說，比事後補充有用得多。**

更廣的一條：**報表者的價值不只是把數字畫對，還包括說出這批數字撐不起哪一種結論。**
