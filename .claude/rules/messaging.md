# 通訊規範

## 星狀拓樸

**所有資訊流一律經過上帝。** 玩家之間不直接通訊，一次都沒有 —— 包含自我介紹階段。

```
        P1   P2   P3
          \   |   /
   P4 ──── [ GOD ] ──── P5      reporter ─── GOD
          /   |   \
        P6   P7   P8   P9
```

reporter 只與上帝通訊（唯一例外：人類觀戰者可直接要求它重建報表，那不影響對局）。

## 上帝發給你的訊息，固定包含四要素

1. 當前存活名單
2. 第幾天／第幾夜、目前階段
3. 你要做什麼，以及**要執行哪一個 skill**
4. 回覆格式與逾時的預設判定

### 四要素有時候在「信箱」那個檔裡

公版內容（天亮公告、指派發言、收票、唱票這類）不再直接送給你，
而是寫成一個檔放進 `game-state/public/mailbox/`。上帝送你的是一則**指路訊息**，
它只保證三件事：現在是哪個階段、**你的信是哪一個檔**、讀完要執行哪一個 skill。

**四要素在那個檔裡，一項都不會少。** 收到指路訊息就去 `Read` 它。

**檔不存在、或內容看起來不是給你的 → 回報上帝，不要自己推進。**
這與發言的必讀清單是同一條紀律：清單是權威，資料夾是現場，對不上就回報。

> 為什麼這樣改：上帝不必再把九份幾乎相同的長訊息生成出來、放進自己的上下文、再逐一送出。
> 這與「逐字稿他只給路徑、你自己去讀」是同一招 —— 只是這次套用在他自己的訊息上。
> 含機密的訊息（身份牌、狼隊、查驗結果、用藥）**仍然直接送給你**，不會進公開信箱。

上帝**不會**在訊息中給你戰術建議、局勢分析或思考方向 —— 那是規則明文禁止的，見 `god-neutrality.md`。若你收到這類內容，可以當場指出來。

## 你回覆的格式

由對應的動作 skill 規定。上帝指派 `/player-speak` 時，格式就寫在該 skill 裡；`/player-vote`、`/player-night-action`、`/player-vote-mvp` 同理。

**照 skill 的格式回覆**，上帝才能確定性地解析你的回應。

## 逐字稿

**上帝不轉貼逐字稿，一次都不轉。** 他只給你路徑。

- 別人的發言原文在 `game-state/public/speech-inbox/`，你自己去讀
- 併好的正式逐字稿在 `game-state/public/03-speeches-dayN.md`，由 reporter 產生
- 你自己的發言也是你自己寫進 inbox，寫完只回上帝一句「已落檔」

> 這同時解決了兩件事：上帝的訊息長度不再隨天數膨脹，
> 而且**他手上沒有可以濃縮的東西** —— 濃縮就是選擇，選擇就是偏袒。

## 逾時

未在該階段回覆，依 `flow.md` 各階段列出的預設判定處理（狼人棄權、預言家空過、女巫不用藥、投票棄票）。上帝會先重發一次澄清訊息。
