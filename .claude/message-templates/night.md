# 訊息模板・夜間

**上帝對玩家的訊息一律從模板渲染，不自由撰寫。** 插槽以 `{{...}}` 標示，
渲染後不得增添模板以外的句子。

**這個目錄玩家也讀得到**，而且公版訊息就是由玩家自己渲染的：

```bash
python .claude/message-templates/render.py <action> --seat P<你的座位> --params <參數>
```

玩家端的說明在 `/player-inbox`；上帝端的 action 索引與渲染規則在
`.claude/skills/god-dispatch/SKILL.md`。

---

## `night_wolf_open` —— 狼人睜眼（並行發給存活狼人）

```
【上帝私訊・第 {{night}} 夜・狼人行動】{{seat}}，天黑了。

■ 當前局面
天數：第 {{night}} 夜
存活 {{alive_count}} 人：{{alive_list}}
你的狼隊友：{{teammates}}

■ 今晚的狼隊長
**{{leader}}**
{{leader_note}}

■ 夜裡只能用暗號
| 類別 | 可用暗號 |
|---|---|
| 指定目標 | `刀 P<n>`、`別刀 P<n>`、`換人`、`自刀` |
| 判斷身分 | `P<n> 像神`、`P<n> 像預言家`、`P<n> 像女巫`、`P<n> 像獵人`、`P<n> 像民`、`不確定` |
| 戰術方向 | `屠神`、`屠民`、`先刀強發言`、`留獵人到白天` |
| 白天分工 | `我悍跳`、`我陪跳`、`我倒鉤`、`我深水`、`P<n> 跳` |
| 表態 | `同意`、`不要`、`等一下`、`你決定` |

不在表內的內容不會被轉達，也不會退回來問你。

■ 這一步你要做什麼
{{role_instruction}}

■ 請執行
`/player-night-action`　（該 skill 會告訴你回覆格式）

逾時視為棄權。請只回覆我，不要私下聯絡隊友。
```

> `{{leader_note}}` 只有兩種值：接任時填「（{{prev_leader}} 已出局，由順位接任）」，
> 其餘情況留空。**不要寫任何其他說明。**
>
> `{{role_instruction}}` 也只有兩種值：
> - 隊長：「你是今晚的隊長。等我把隊友的暗號轉給你之後，由你拍板。」
> - 非隊長：「用暗號表達你的意見，我會具名轉給隊長。」

## `night_wolf_relay` —— 把隊友暗號轉給隊長

```
【上帝私訊・第 {{night}} 夜・狼隊暗號】{{seat}}，以下是隊友的暗號，原文轉貼。

{{signals_verbatim}}

■ 現在請你拍板
必填：今晚刀誰（可自刀，空刀不成立）、接班順位。
選填：悍跳、陪跳、倒鉤、深水 —— **可以完全不填。**

■ 請執行
`/player-night-action`

逾時我會重發一次；再逾時由接班順位第一位代為決定。
```

> `{{signals_verbatim}}` 一律**具名、原文、依座位號排序**。
> 不摘要、不排序成「多數意見」、不加任何評語。逾時未交的狼標為「（未提交）」。
> **只剩一狼時**：他自己就是隊長，沒有隊友暗號可轉 —— 這則照發，但把
> `{{signals_verbatim}}` 連同它的標題整段省略，只保留「現在請你拍板」以下。

## `night_wolf_plan` —— 把隊長的決定轉達給其他狼

```
【上帝私訊・第 {{night}} 夜・狼隊決定】{{seat}}，隊長 {{leader}} 已決定。

刀：{{kill}}
接班順位：{{succession}}
{{assignments}}

這則不需要回覆，天亮見。
```

> `{{assignments}}` 只列隊長**實際填了**的分工，一行一項（例如「悍跳：Px」）。
> 隊長全部留空時，這一行整段省略，**不要補任何說明**。

## `night_seer` —— 預言家查驗

```
【上帝私訊・第 {{night}} 夜・預言家查驗】{{seat}}，請執行 `/player-night-action` 指定查驗對象。

■ 當前局面
天數：第 {{night}} 夜
存活 {{alive_count}} 人：{{alive_list}}

從你以外的存活玩家中指定一位。我會回覆該玩家的**陣營**（好人／狼人），不含具體身份。
逾時視為空過。

■ 請執行
`/player-night-action`
```

```
**{{target}} —— {{camp_result}}**

「好人」代表非狼陣營，不代表是平民。
你的夜間行動已完成。
```
