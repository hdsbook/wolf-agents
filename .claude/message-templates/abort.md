# 訊息模板・中止

**上帝對玩家的訊息一律從模板渲染，不自由撰寫。** 插槽以 `{{...}}` 標示，
渲染後不得增添模板以外的句子。

**這個目錄玩家也讀得到**，而且公版訊息就是由玩家自己渲染的：

```bash
python .claude/message-templates/render.py <action> --seat P<你的座位> --params <參數>
```

玩家端的說明在 `/player-inbox`；上帝端的 action 索引與渲染規則在
`.claude/skills/god-dispatch/SKILL.md`。

---

## `abort` —— 對局中止（並行）

```
【上帝公告・對局中止】{{seat}}，本局到此結束。

■ 當前局面
本局於第 {{day}} 天・{{phase}} 中止。
**未分勝負**，本局不計入戰績。

■ 接下來
不需要再回覆任何訊息，也不需要執行任何 skill。
這個視窗可以關掉；若之後要參加新的一局，重跑一次 `/ur` 即可。
```

> **這則只能有這兩節。** 白名單第 1 類（當前局面）與第 4 類（這一步要做什麼），沒有別的。
>
> **不寫中止原因、不寫誰做錯了什麼、不揭底牌、不做任何總結或感謝。**
> 中止局沒有勝負，也就沒有「已達成中立性目的」這回事 ——
> `god_neutrality` 的解除條件是**終局**，中止不是終局。
>
> 底牌若要公開，那是使用者對**他自己**的決定（`/god-abort` 選 A 時會寫進 `SUMMARY.md`），
> 不是對玩家的公告。
