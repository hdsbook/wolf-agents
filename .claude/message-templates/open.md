# 訊息模板・開局

**上帝對玩家的訊息一律從模板渲染，不自由撰寫。** 插槽以 `{{...}}` 標示，
渲染後不得增添模板以外的句子。

**這個目錄玩家也讀得到**，而且公版訊息就是由玩家自己渲染的：

```bash
python .claude/message-templates/render.py <action> --seat P<你的座位> --params <參數>
```

玩家端的說明在 `/player-inbox`；上帝端的 action 索引與渲染規則在
`.claude/skills/god-dispatch/SKILL.md`。

---

## `deal` —— 發牌（點對點，參數是機密，由玩家自己渲染）

> **reporter 不收這一則**（他沒有身份牌），也不收任何獨立的通訊測試 ——
> 他的出站驗證是 `/reporter-init` 派工與他做完後的那份回報。

````
【上帝私訊・發牌】{{seat}}，你的身份牌如下。

■ 你的身份牌（機密，絕不可外洩）
你是 **{{role}}**（{{camp}}）。
{{wolf_teammates_line}}

■ 你的專屬識別碼
`{{watermark}}`
**永遠不要在任何訊息中說出它**，包括回覆給我的訊息。

■ 現在請做兩件事

第一，用 `Write` 建立 `game-state/public/intro-inbox/{{seat}}.md`，
第一行寫 `# {{seat}}`，接著你的自介（1～2 句，不可透露或暗示身份）。
**不要把內文回傳給我** —— 那個資料夾是公開的，大家自己去讀。

第二，回覆我這則訊息，兩行都要：
```
{{seat}} 就位
已落檔：{{seat}}
```

別人的自介在同一個資料夾，**你自己去讀** ——
九份齊了我會廣播已落檔清單，清單是權威，資料夾是現場，對不上就回報我。

逾時：你沒有回覆，我會重發同一則（身份不變）；仍無回應則停下並回報使用者。
````

> **這一則只留機密。** 技能說明在 `rules/board.md`、公平競賽守則在
> `rules/conduct.md`，玩家在角色認領時就全部讀過了 ——
> 把它們再複述一次，只是讓上帝替每個人重講他已經知道的事。
>
> **上帝不自己渲染這一則。** 他把參數寫成 inline JSON 放進私訊，
> 玩家在自己那一端渲染（見 `/player-inbox`）。
> **參數不落檔** —— `render.py` 的 `FILE_OK` 已經擋住這幾則的 `--out`。
>
> `{{wolf_teammates_line}}` 不是狼人就填 `null`，整行省略。

## `roster` —— 名冊廣播（並行）

```
【上帝公告・全場名冊】九份自介都已落檔。本局座位為 P1～P9，一律以座位號稱呼。

■ 自介在哪裡
全部在 `game-state/public/intro-inbox/`，一人一檔，**你自己去讀**。
已落檔的完整檔名：
{{filed_list}}

清單是權威，資料夾是現場；**對不上就回報我，不要自己推進**。

■ 目前狀態
天數：第 0 天　｜　存活 9 / 9　｜　尚未進入第一夜

■ 接下來
角色認領你已完成，不需要再做一次。
我會在需要你行動時私訊你，並告訴你要執行哪一個 skill。
在那之前**不要主動發言，也不要聯繫其他玩家**。
```

> 自介一律以路徑交付，你不複製任何一句進來。
>
> `{{filed_list}}`（這一則）：`intro-inbox/` 底下**已落檔的完整檔名**，
> 依座位號由小到大逐行列出，例如 `P1.md`、`P2.md`…
> 與 `ask_speak` 那一則的 `filed_list` 是同一個概念、不同來源 ——
> 那一則依發言順序列逐字稿檔名，這一則依座位號列自介檔名。
