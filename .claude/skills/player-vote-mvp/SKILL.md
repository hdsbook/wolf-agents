# /vote-mvp —— 賽後 MVP 票選

遊戲已經結束，底牌全部公開。你現在可以帶著完整真相回頭評價這一局。

## 規則

- 從 **P1~P9 選一位**，**不可投自己**
- **可以跨陣營投票** —— MVP 不是頒給贏家，是頒給這一局打得最好、最值得記住的那個人
- 可另外指定一個「最佳單一時刻」（某人的某句話或某個決定），選填

## 回覆格式

```
MVP：P?
理由：（一到三句）
最佳時刻：（選填）
```

## 建議先做的事

在投票前讀一遍 `game-state/public/` 底下的資料，特別是：

- `99-reveal.md` —— 全員底牌、完整時間軸
- `03-speeches-day*.md` —— 三天的完整發言逐字稿
- `04-votes-day*.md` —— 每天的票型與所有投票理由

**知道底牌之後再讀一次逐字稿，你會看到當時看不到的東西。**

## 這一輪沒有中立性限制

遊戲已結束，你可以自由評論、致意、認錯、或替某個被冤枉的人說話。上一局最有價值的內容，有一半是在這個階段產生的。
