# /player-night-action —— 夜間行動

## 先確認

你已執行過 `/ur p<n>`，並且**知道自己的底牌**。
上帝的私訊會標明這是哪一種行動 —— 照那個走，只填你自己那一節。

---

## 狼人

**夜裡不能自由交談，只能用暗號。** 上帝的私訊會告訴你**誰是狼隊長** ——
你是隊長就走 A，不是就走 B。

### 暗號表（只能用這些，不在表內的一律無效）

指涉某個人的暗號要附座位號。可以組合多個，一行一個。

| 類別 | 可用暗號 |
|---|---|
| 指定目標 | `刀 P<n>`、`別刀 P<n>`、`換人`、`自刀` |
| 判斷身分 | `P<n> 像神`、`P<n> 像預言家`、`P<n> 像女巫`、`P<n> 像獵人`、`P<n> 像民`、`不確定` |
| 戰術方向 | `屠神`、`屠民`、`先刀強發言`、`留獵人到白天` |
| 白天分工 | `我悍跳`、`我陪跳`、`我倒鉤`、`我深水`、`P<n> 跳` |
| 表態 | `同意`、`不要`、`等一下`、`你決定` |

**不要寫暗號以外的句子。** 寫了也不會被轉達 —— 上帝只搬表內的暗號，
其餘視為無效（不猜測你的意思，也不會退回來問你）。

### A. 你是狼隊長

先看上帝轉來的隊友暗號（具名、原文），然後拍板。**你的決定直接成立，不需要誰同意。**

```
刀：P?
接班順位：P?, P?
悍跳：P?
陪跳：P?
倒鉤：P?
深水：P?
```

- **`刀` 與 `接班順位` 必填。** 刀可以指向自己人（自刀）；**空刀不成立**。
- **`接班順位`** 是你死後誰接任隊長、再來誰 —— 列出你以外的存活狼人，由先到後。
  **只剩你一隻狼時填「無」。**
- **後面四項是選填，可以整行不寫。** 第一夜資訊不夠就別硬湊，
  沒有分工時大家白天各自判斷，那完全正常。
- 分工**不強制執行**：說好悍跳的人白天沒跳，不會有任何懲罰或提示。

### B. 你不是隊長

用暗號表達意見，上帝會**具名原文**轉給隊長，由他決定。

```
暗號：
刀 P7
P7 像預言家
我倒鉤
```

逾時視為棄權，不影響隊長的決定。隊長決定後，上帝會把結果轉達給你。

---

**不要私下聯絡隊友** —— 狼隊的協調由上帝居中主持，私聯會被稽核抓到。

## 預言家：查驗

從你以外的存活玩家中指定一位。上帝會回覆該玩家的**陣營**（好人／狼人），不含具體身份。

```
查驗對象：P?
（可附一句考量，選填）
```

逾時視為**空過**，本夜無查驗結果。

---

## 女巫：用藥

上帝會告知今晚被刀者與兩瓶藥的剩餘狀態。擇一：

```
決定：用解藥救 P?
理由：（一句話）
```
```
決定：用毒藥毒 P?
理由：（一句話）
```
```
決定：不用藥
理由：（一句話）
```

規則：**同一晚不可同時使用兩瓶藥**；解藥只能救當晚被刀者；**獵人若被你毒死則無法開槍**。逾時視為不用藥。

---

## 獵人：開槍

你死亡後（被狼刀或被投票放逐）才會收到這則請求。**被女巫毒死則不會有這一步。**

```
槍口：P?
理由：（一句話）
```

或

```
槍口：不開槍
理由：（一句話）
```

你也可以在生前的發言或投票中預先宣告槍口，並隨時更新。

- 理由不會被公開，但會被記錄，終局戰報可能引用
