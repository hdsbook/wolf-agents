# /night-action —— 夜間行動

## 先確認

你已執行過 `/join-as p<n>`，並且**知道自己的底牌**。
上帝的私訊會標明這是哪一種行動 —— 照那個走，只填你自己那一節。

---

## 狼人：刀人提案

從**你和隊友以外**的存活玩家中選一位。

```
目標：P?
理由：（一句話）
```

**匿名第二輪**：若三人提案不一致，上帝會把提案打亂順序、抹去署名後發回來，請在候選名單中做最終表態：

```
最終目標：P?
一句話理由：
```

規則：一致直接成立；不一致取多數決；二輪仍無多數由上帝隨機裁決。**空刀不成立。** 逾時視為棄權。

**不要私下聯絡隊友** —— 狼隊的協調由上帝居中主持，私聯會被稽核抓到。

---

## 預言家：查驗

從你以外的存活玩家中指定一位。上帝會回覆該玩家的**陣營**（好人／狼人），不含具體身份。

```
查驗對象：P?
（可附一句考量，選填）
```

逾時視為**空過**，本夜無查驗結果。

---

## 女巫：用藥

上帝會告知今晚被刀者與兩瓶藥的剩餘狀態。擇一：

```
決定：用解藥救 P?
理由：（一句話）
```
```
決定：用毒藥毒 P?
理由：（一句話）
```
```
決定：不用藥
理由：（一句話）
```

規則：**同一晚不可同時使用兩瓶藥**；解藥只能救當晚被刀者；**獵人若被你毒死則無法開槍**。逾時視為不用藥。

---

## 獵人：開槍

你死亡後（被狼刀或被投票放逐）才會收到這則請求。**被女巫毒死則不會有這一步。**

```
槍口：P?
理由：（一句話）
```

或

```
槍口：不開槍
理由：（一句話）
```

你也可以在生前的發言或投票中預先宣告槍口，並隨時更新。

---

## 共同規則

- **不可提及你的專屬識別碼**
- 只回覆上帝，不聯繫其他玩家
- 理由不會被公開，但會被記錄，終局戰報可能引用
