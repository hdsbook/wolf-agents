# /reporter-collect —— 併發言逐字稿

## 用法

```
/reporter-collect <天數> <輪次>
```

`<輪次>`：發言輪 `seq`／PK `pk`。

## 先確認

你已執行過 `/ur reporter`。

## 這支 skill 為什麼存在

發言原本由上帝逐字重打進 `03-speeches-dayN.md`。那是純搬運，卻讓每一則發言
多經過上帝的上下文一次，而且**給了他一個接觸發言內容的機會** ——
上一局的偏袒就是從這種機會裡長出來的。

現在玩家自己寫檔，你負責併。**你也是純搬運，一樣不許改寫。**

## 步驟

### 1. 讀 inbox

```
game-state/public/speech-inbox/d<天>-<輪次>-P<n>.md
```

掃出該天該輪已存在的全部檔案。**檔案不存在就是那位沒交** —— 跳過他，
不要留空標題、不要註記「棄權」，逐字稿只記錄實際發生的發言。

### 2. 組標題

```
## P6・風鈴【宣告：預言家】
```

- 座位號取自**檔名**
- 暱稱查 `game-state/public/00-players.md`
- 宣告取自該檔**最後一行** `【宣告】<值>` 的那個 token

### 3. 檔頭（該天第一次併檔時寫一次）

```markdown
# 第 N 天・發言逐字稿

發言順序（隨機起始位 P6，順）：P6 → P7 → P8 → P9 → P1 → P2 → P3 → P4 → P5

---
```

- **順序那一行原文照抄自上帝的併檔指示**，他抽的他才知道。指示裡沒有就整行省略，
  **不要自己推斷順序** —— 你看到的落檔先後不等於他公告的順序。
- 檔頭只寫一次。第二次以後的併檔直接往下追加。

> 這個檔頭是歸檔格式的一部分，`game-archive/` 裡每一份逐字稿都有它。
> 少寫了不會有任何錯誤訊息，但歷屆對局的格式就從這一局開始不一致。

### 4. 追加寫入

| 模式 | 目標檔 | 額外處理 |
|---|---|---|
| 發言輪 `seq` | `03-speeches-day<N>.md` | 依**上帝公告的發言順序**排列 |
| PK `pk` | `03-speeches-day<N>-pk.md` | 依座位號 |

**追加，不覆寫。** 每位落檔就跑一次，所以同一份檔會被追加很多次 ——
每次只寫「還沒進去的那幾位」，寫之前先讀現有內容確認誰已經在裡面。

**這是冪等的**：同一位重複跑不應該產生第二份。判準是標題行的座位號。

### 5. 接著畫圖

併完直接跑 `/reporter-build`（不加 `spoiler` —— 發言本來就是公開的）。

## 三條紀律

- **純字串搬運。** 不改寫、不修錯字、不調整段落、不歸納。玩家寫什麼就是什麼。
- **宣告漏填寫 `【宣告：未填】`**，並回報上帝由他補問。**絕對不要替他判讀**
  —— 從發言內容推斷他跳了什麼是對發言的解讀，那是上帝與你都不做的事。
- **填了列舉以外的值就照抄。** `render.py` 會靜默降級（`render.py:70`），
  不需要你在這裡修正它。

> 正文最後那一行 `【宣告】<值>` **要保留在內文裡**，不要因為已經抄進標題就刪掉。
> 正文是權威來源，標題只是索引；`render.py` 在標題缺漏時會回頭掃正文兜底。

## 不要回報，除非出事

**併完不用回上帝。** 他送出指派後就往下走了，你的「收到」「已完成」只會打斷他的流程 ——
發言輪一天有 9 則指派，9 則回覆就是 9 次打斷。

**只有這幾種情況要主動出聲**，而且直接說問題是什麼：

| 情況 | 為什麼要說 |
|---|---|
| `/reporter-verify` 沒過 | 紀錄本身壞了，繼續推進會讓錯誤擴散到後面每一天 |
| 上帝給的必讀清單與 inbox 對不上 | 有人沒真的落檔，卻回報了「已落檔」 |
| 身份宣告漏填（`【宣告：未填】`） | 要他補問，那是他的動作不是你的 |
| 同一位在同一輪有兩份內容不同的檔 | 落檔規則被打破了，你不該自己選一份 |
| 有人的發言正文超過 **400 字** | 那是 `/player-speak` 的上限，超了要讓上帝知道 |

> **超長怎麼處理**：照原文併進逐字稿，**一個字都不刪**，只在回報上帝時
> 說「P<n> 第 N 天發言 <實際字數> 字，超過 400 字上限」。
>
> 字數＝正文**不含空白與換行**的字元數，**最後那行 `【宣告】<值>` 不計入**。
> 這跟純字串搬運的紀律不衝突：你只是量它，沒有動它。
> 刪節是對發言的改寫，那是你與上帝都不做的事。

其餘一切正常就安靜做完。**沉默即正常**，這是上帝那邊的預期。

## 落後了怎麼辦

你可能同時收到好幾則併檔指派。**不要逐則跑** ——
直接處理到「該天全部已落檔的檔案都進去了」為止，一次補完。

**併檔落後不影響對局**：玩家讀的是 inbox 原文，不是你的產出。
你的產出服務的是報表、歸檔與爭議時的引用。
