# /player-speak —— 白天發言

## 先確認

你已執行過 `/ur p<n>`。若沒有，先跑那個。

## 規範

- **400 字以內**，一到三段，言之有物、帶推理與說服力
  - 字數只算正文，**最後那行 `【宣告】<值>` 不計入**；空白與換行也不計
  - 這是上限不是目標 —— 講完就停，湊字數是划水的一種
  - 線下狼人殺限的是時間，這裡限字數，理由一樣：**別讓一個人佔掉整個白天**
- 你的發言會被完整記錄成逐字稿，後面的人與明天的人都讀得到
- **可以說謊、跳身份、悍跳、隱瞞、誤導** —— 這些是合法戰術
- **不可提及你的專屬識別碼**（在任何訊息中都不可，包括回覆給上帝）
- 不要要求上帝給你戰術建議 —— 規則禁止他那麼做

## 發言方式

依上帝公告的順位一個一個講。輪到你時，前面的人都已落檔，你讀得到全部；
後面的人這時候還沒交，他們會讀到你這一則。

**別人的發言你自己去讀** —— inbox 是公開目錄，見 `rules/conduct.md`。

## 必答項

若前面的發言中有人**指名要求你回答某個問題**，你的發言必須正面處理它。
迴避會被後面的人記在帳上，而且逐字稿留著。

## 發言寫在哪裡

**你的發言由你自己寫檔，不要貼給上帝。**

```
game-state/public/speech-inbox/d<天>-<輪次>-P<座位>.md
```

| 欄位 | 值 |
|---|---|
| `<天>` | 阿拉伯數字，第 1 天就是 `1` |
| `<輪次>` | 發言輪 `seq`／PK `pk` |
| `<座位>` | 你的座位號，大寫 `P` |

例：`d2-seq-P7.md`。**上帝的私訊會直接給你完整路徑，照抄即可。**

三條紀律：

- **用 Write 寫一份新檔，不要 append、不要編輯別人的檔。** 一人一檔就不會互相覆蓋。
- **檔案內容就是發言正文本身**，不加標題、不加前綴、不寫自己的座位號 ——
  那些由 reporter 併檔時補上。最後一行照樣是 `【宣告】<值>`。
- 寫完回上帝一句「P<n> 第 N 天 <輪次> 已落檔」，**不要把內文再貼一次**。

## 別人的發言怎麼讀

**上帝的私訊裡有一張清單，列出你發言前必須讀完的檔名。**

那張清單是權威 —— 它列的每一份都已經落檔，缺一份都不能動筆。
`speech-inbox/` 是現場，兩邊對不上（清單有、檔案不在）就**回報上帝**，不要自己推進。

清單＝本日到你之前的全部發言，讀完就是完整資訊。

併好的正式逐字稿在 `game-state/public/03-speeches-dayN.md`（由 reporter 產生），
但它可能落後 —— **要最新的就讀 inbox**。

若你要**明確表態投票意向**，在段落中寫清楚（例如「我今天的票給 P?」）。
沒有人會替你整理成票型指向，看的人自己讀。

## 身份宣告（每次發言必填）

發言正文之後空一行，**最後一行**固定寫：

```
【宣告】預言家
```

**每一次發言都要有這一行**，包含 PK 發言。沒有要宣稱身份也要寫 `【宣告】不表態`。

值只能填下列其中一個，**不加任何補述**：

| 值 | 意思 |
|---|---|
| `預言家`／`女巫`／`獵人` | 宣稱自己是那個神職 |
| `神職` | 宣稱是神職，但不說是哪一個 |
| `平民` | 宣稱是平民 |
| `好人` | 宣稱是好人陣營，不指定平民或神職 |
| `狼人` | 自曝 |
| `不表態` | 這次不宣稱任何身份 |

**這一行可以說謊。** 悍跳就是填 `預言家` 而底牌是狼 —— 那是合法戰術，
跟發言本文一樣不受真實性約束。

**改口也合法。** 第 1 天填 `不表態`、第 2 天填 `預言家`，系統會逐天記錄，不會阻止你。
但變化本身是公開的，別人看得到你改過口。

這一行會**原樣進入公開逐字稿** —— 身份宣稱本來就是公開資訊，這不是洩漏。

> **為什麼要有這個欄位。** 上帝不能替你判讀「你剛才那段話算不算跳預言家」——
> 那是對發言的解讀，`god-neutrality.md` 明文禁止。由你自己填，上帝只做搬運，
> 報表才能呈現全場的宣稱狀況而不需要任何人做判斷。
>
> 填什麼由你決定，**這個欄位不規範打法**。

## 這支 skill 不提供打法

推理方向、要相信誰、要施壓誰、用什麼風格說話 —— 全部由你自己決定。
上面規範的只有長度、必答項與回覆格式，那是為了讓全場格式一致、讓上帝能確定性地轉貼。

**這是刻意的。** 由系統統一發給九個人的打法建議，會讓全場往同一個方向想，
而那個方向是主辦方選的 —— 那等於主辦方在替你們決定這局怎麼打。
