# /player-inbox —— 把上帝的參數渲染成完整訊息

## 什麼時候用

上帝的訊息長這樣的時候：

```
【上帝・第 2 天・投票階段】你這一步的指令請你自己渲染出來。

■ 執行這一行（把 `<你的座位>` 換成你自己的座位號，例如 P3）
...
```

**照抄那一行執行就好**，把 `<你的座位>` 換成你自己的座位號。

## 指令

```bash
python .claude/message-templates/render.py <action> --seat P<你的座位號> --params <參數>
```

`<action>` 與 `<參數>` 上帝都寫在訊息裡了，原樣照抄。
印出來的就是完整訊息：當前局面、你要做什麼、回覆格式與逾時的預設判定，一項都不少。

**接著照它最後說的去執行對應的 skill**（`/player-speak`、`/player-vote`…）。

## 為什麼要你自己跑

上帝原本要把九份幾乎相同的長訊息一則一則生成出來再送出。
現在他只給參數，訊息由你這一端渲染 —— **同樣的內容，他少扛九倍的工作。**

這跟逐字稿是同一個道理：他不轉貼發言，只給你路徑，你自己去讀。

## 出狀況的時候

**渲染不出來就回報上帝，不要自己補內容、也不要照著殘缺的版本行動。**

| 你看到 | 意思 |
|---|---|
| `參數裡找不到 P<n> 的那一份` | 上帝漏了你，或你座位號打錯了 |
| `參數不是合法的 JSON` | 參數檔壞了 |
| `插槽沒填 {{...}}` | 上帝漏填欄位 |
| `找不到參數檔` | 路徑不對，或他還沒寫好 |

原文回報，一個字都不要改 —— 那幾行是他修的依據。

**印出來的內容看起來不是給你的**（例如順位、座位對不上）也一樣回報。
這與發言的必讀清單是同一條紀律：對不上就回報，不要自己推進。

## 兩種形式：參數檔路徑、inline JSON

| 你看到的 `--params` | 這是什麼 |
|---|---|
| `game-state/public/mailbox/.../params.json` | 公版廣播。九個人拿到的字完全相同，參數檔是公開的 |
| `'{"seat":"P3", ...}'` 直接寫在訊息裡 | **機密訊息**。參數本身就是機密，所以不落檔、只進點對點私訊 |

两種都是照抄那一行執行，做法完全一樣。

**機密那一種多一條規矩**：渲染出來的內容（身份牌、狼隊名單、查驗結果…）
**不要回傳給上帝、不要貼進任何公開檔**。你只回它要求的那幾行。

## 跑不動指令的時候：自己對照模板讀

沒有 python、指令被擋下、或者執行報錯 —— **那不是死路，是另一條正式路徑。**

模板是公開的，JSON 就在訊息裡，所以你自己就能把它們合起來：

1. 讀 `.claude/message-templates/` 底下對應的模板檔（`--list` 那張表說了誰在哪一份，
   或者在那個目錄裡搜 action 名字），找到那個 `action` 的模板本文
2. 把 JSON 裡的值一個一個代進 `{{...}}` 插槽
3. 值是 `null` 的插槽，**整行省略**
4. 參數有 `recipients` 陣列時，只取 `to` 等於你座位的那一份；
   `common` 是大家共用的，同名欄位以你那一份為準

做完回報上帝一句「以人工對照方式讀取」，然後照常行動。
**代不出來、或代完還有看不懂的地方，才回報他，不要自己編內容。**

## 兩件事要知道

- **模板是公開的。** `.claude/message-templates/` 你讀得到，裡面只有插槽沒有值。
  `rules/god-neutrality.md` 讓你拿模板監督上帝 —— 模板藏起來那條監督權就是空的。
  **看到他填進去的值夾帶了評價或建議，你可以當場指出來。**
- **身份牌、狼隊、查驗結果、用藥、獵人開槍那幾則也走這條** ——
  差別只在於它們的參數是直接寫在私訊裡的 inline JSON，不落檔。
