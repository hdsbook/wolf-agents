# /vote —— 投票

## 先確認

你已執行過 `/join-as p<n>`。

## 規則

- 從**存活玩家**中選一位放逐，或棄票
- **你的票可以與發言時的表態不同** —— 讀完全部逐字稿後改變主意完全合理，但別人會注意到落差
- 未回覆視為**棄票**
- 得票最高者出局；平票進 PK；PK 再平票則流局
- **PK 重投時**：只能在 PK 對象之間二選一，或棄票；PK 對象本人不投票

## 回覆格式（請嚴格照這個格式）

```
投票：P?
理由：（一句話）
```

或

```
投票：棄票
理由：（一句話）
```

PK 重投時把第一行改成 `PK投票：P?`。

**若你是獵人且想更新開槍宣告**，在理由後另起一行：

```
槍口：P?
```

## 為什麼格式要一致

上帝要唱票並公開全部理由，`投票：` 這一行會被程式化解析。
格式跑掉會拖慢流程，也可能被誤讀。**理由可以自由發揮，第一行不要。**

## 你的票會被公開

唱票時，**你投給誰、以及你的理由，都會原文公布給全場**。票是最誠實的證據 —— 發言宣告投 A、開票投 B 是可查證的紀錄，別人會拿它做文章。要改票就明說你改了。
