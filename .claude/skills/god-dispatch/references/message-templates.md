# 訊息模板（上帝專用）

**所有對玩家的訊息一律從這裡渲染。模板只有欄位插槽，沒有自由段落。**

覺得某個情境模板不夠用？**去改模板**（對所有人一致生效），不要這一次多寫幾句。

插槽以 `{{...}}` 標示。渲染後不得增添模板以外的句子。

---

## `ping_reporter` —— 通訊測試（reporter 專用）

> **只有 reporter 走這一則。** 玩家不收獨立的通訊測試 —— 他們的通訊測試、暱稱指派
> 與身份牌合併在下面的 `deal` 那一則裡（reporter 沒有身份牌，所以不能收 `deal`）。

```
【上帝・通訊測試】reporter，請回覆「reporter 就位」。

我是本局上帝。收到這則訊息代表雙向通訊正常。
請只回覆「reporter 就位」四個字，不要附加其他內容。
```

## `deal` —— 發牌（並行 9 則，玩家唯一的開局訊息）

```
【上帝私訊・發牌】{{seat}}，這是你的身份牌，請仔細讀完。

我是本局上帝。這是我發給你的第一則訊息，**它同時就是通訊測試** ——
你照最後一段的格式回覆我，就代表雙向通訊正常。

■ 你的身份牌（機密，絕不可外洩）
你是 **{{role}}**（{{camp}}）。
{{role_ability}}
{{wolf_teammates_line}}

■ 你的專屬識別碼
`{{watermark}}`
記住它，但**永遠不要在任何訊息中說出它**，包括回覆給我的訊息。

■ 規則
公開規則在 `.claude/rules/`，六份都請讀過：board / flow / conduct / messaging / god-neutrality / glossary。
其中 `god-neutrality.md` 是我的行為約束，你可以據此監督我。

■ 你這一局的暱稱
**{{nickname}}** —— 由我指派。全場公開，之後所有公開紀錄一律以
「{{seat}}・{{nickname}}」稱呼你。暱稱不需要你確認，也不接受更換。

■ 開局前的承諾
請先讀 `.claude/rules/conduct.md`。重點：
- **說謊、跳身份、悍跳、隱瞞、誤導完全合法**，那是遊戲玩法
- 讀取 transcript／`game-state/secret/`／他人檔案、繞過我通訊 —— **這些是作弊**
- 這些路徑由 hook 實際攔截，被擋下時會留下紀錄。**被擋到不是懲罰，是機制** —— 回報我即可
- 我每個夜晚都會稽核全部玩家的工具使用紀錄
- 回覆我的訊息時，**不要寫出斜線開頭的指令字串**，改用文字敘述（例如「角色認領已完成」）

■ 現在請做兩件事

**第一，把自我介紹寫進檔案**（破冰用，1～2 句）：

```
game-state/public/intro-inbox/{{seat}}.md
```

檔案內容就寫這樣，第一行是標題，接著你的自介：

```
# {{seat}}・{{nickname}}

（你的自介，1~2 句）
```

**自介不可透露或暗示你的身份牌。** 這只是破冰，正式推理留到白天。
**不要把內文回傳給我** —— 那個資料夾是公開的，大家自己去讀。

**第二，回覆我這則訊息**，三行都要，格式：
```
{{seat}}・{{nickname}} 就位
已落檔：{{seat}}
承諾：{{seat}} 承諾遵守公平競賽守則。
```
第一行是通訊測試，請照我指派的暱稱原樣寫。
```

> **上帝不經手自介內文。** 他只收「已落檔」的回報，不讀、不轉貼、不彙整。
> 這與白天的發言是同一條規矩（見 `god-neutrality.md`「逐字稿：上帝完全不經手」）——
> 濃縮就是選擇，選擇就是偏袒，所以他手上不該有可以濃縮的東西。

> **暱稱與身份牌同一則告知，但抽選早於洗牌。** 上帝先抽暱稱、再洗牌，
> 抽的那一刻連他自己都還不知道任何人的底牌 —— 所以座位與暱稱的對應
> 在結構上不可能攜帶身份資訊。合併的是送達時機，不是產生順序。
> 名單池與抽法在 `.claude/skills/god-open/SKILL.md` 第 4 步。

> **這是玩家在開局唯一會收到的訊息。** 通訊測試、暱稱、身份牌、自介落檔、
> 公平競賽承諾全部在這一則裡完成，玩家一次回三行。

寫完檔案後，回我一句「{{seat}} 第 {{day}} 天 seq 已落檔」即可，**不要把內文再貼給我**。
發言的**最後一行**請附上 `【宣告】<值>`，每次必填，不宣稱身份就寫 `【宣告】不表態`。
可填的值列在 `/player-speak` 裡。

■ 逾時的預設判定
未在合理時間內落檔視為棄權，本輪不留下你的發言。
```

> `filed_list`：本日已回報落檔的座位，**逐行列出完整檔名**，依發言順序：
> ```
> d{{day}}-seq-P6.md
> d{{day}}-seq-P7.md
> ```
> 第一位發言時填「（你是本日第一位，還沒有人落檔）」。
>
> **這張清單是事實不是摘要** —— 誰講完了屬於「當前局面」，白名單第 1 類。
> 它的作用是讓玩家**驗證自己有沒有漏讀**：清單是權威，資料夾是現場，兩邊對不上就是異常。
>
> **這則模板仍然不含任何逐字稿，長度與天數無關。**
>
> 原本的「目前票型指向」欄位已移除：誰說要投誰寫在逐字稿裡，玩家自己讀得到，
> 由上帝整理等於替他做判讀。
>
> **PK 發言沿用這個模板**，檔名與回報用語的輪次欄改寫 `pk`
> （`d{{day}}-pk-{{seat}}.md`，回報「{{seat}} 第 {{day}} 天 PK 已落檔」），
> 只發給平票的那兩位，`{{n}}/{{total}}` 也改成「第 1／2 位」。
