# /god-abort —— 中止一局

**中止就是：立刻停、全部刪、不提問。**

使用者說停的時候，他要的是停下來，不是一份收場流程。
這支 skill 的目的是讓那件事在一個回合內做完。

**用哪一支的判準：`99-reveal.md` 存在嗎？**
存在＝這局打完了，跑 `/god-archive` 歸檔。不存在＝沒有勝負，跑這一支，無產出。

## 不要做的事

- **不要問任何選擇題。** 沒有要保留什麼，全部刪。
- **不要備份。** roster 也不用 —— 它最後會被清成空的，本來就不需要留。
- **不要歸檔、不要寫 SUMMARY、不要碰 `game-archive/`。**
  中止局沒有勝負，寫進正式局號只會製造假資料。
- **不要總結、不要分析、不要道謝。** 使用者喊停的時候不想讀東西。

> 唯一該停下來問的情況：**使用者沒有明說要中止**，你只是猜他想停。
> 只要他講了「停」「中止」「清掉」「不要了」，就直接往下跑，一個字都不要問。

## 1. 立刻停止主持

收到指令的當下就停，**不要把手上那個階段跑完**。

不再發任何流程訊息、不再等玩家回覆（已在路上的一律忽略）、不再通知 reporter。

## 2. 刪光本局內容

刪掉 `game-state/` 的 `public/`、`secret/`、`report/` 底下全部檔案，
只留 `README.md` 與三個 `.gitkeep`。

順手把稽核紀錄清成 0 byte（**清空不是刪除**，留著檔案 hook 才不必處理不存在的分支）：

```bash
: > .claude/hooks/access.log
```

> `rm -rf` 加萬用字元可能被權限分類器擋下。擋下時**不要重試同一條** ——
> 改用 Python 列出檔名後逐檔刪除。那是同一件事的另一種寫法，不是繞過。

## 3. 最後：把 roster 清成空的

```bash
echo "{}" > game-state/public/roster.json
```

**這一步一定在刪除之後做**，否則會被上一步一起刪掉。

roster 空的時候存取控制一律放行（`guard_secrets.py` 的 bootstrap 分支），
所以清空不會把任何人鎖在門外。下一局所有人重跑一次角色認領就會重新填滿。

## 4. 通知（**預設不做**）

**預設不通知任何人。** 玩家的 session 停在等訊息是正常的，使用者自己會收掉視窗。

使用者**主動要求**時，才走 `/god-dispatch abort` 模板並行發給全體 ——
那則模板只有兩節，**不寫原因、不揭底牌、不做總結**。中立性的解除條件是終局，中止不是終局。

## 5. 驗證

```bash
find game-state -type f | sort   # README.md + 三個 .gitkeep + roster.json
cat game-state/public/roster.json    # {}
wc -c < .claude/hooks/access.log     # 0
```

底牌殘留掃描**只掃 `game-state/`**。`game-archive/` 的命中是過去已終局的局，
底牌本來就公開，**不是殘留**，不要列進報告。

## 6. 回報

**兩行，不要更多。**

```
本局已中止，game-state/ 清回骨架，roster 已清空。未歸檔。
要開下一局的話，11 個角色都重跑一次角色認領就可以。
```

不要附刪除清單、不要總結這一局、不要解釋你為什麼這樣做 —— 除非他問。
