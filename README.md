# 狼人殺・claude code agent view・多 Agent 對局系統

用 claude agent view 模式，開啟 **11 agent** 跑一場 9 人標準局狼人殺：
**1 個上帝（god）＋ 9 個玩家（p1~p9）＋ 1 個播報者（reporter）。**

玩家彼此完全隔離，所有資訊流經過上帝；上帝對玩家嚴格中立，播報者會進行完整播報。

---

## Getting Started

在專案資料夾進入 claude agents 模式

```
cd wolf/
claude agents
```

進入 agent view 模式後，建立11個agents
於專案資料夾執行 `ur <role>` 指定角色： (意指 you are ...)

- `ur god`        建立主持人 (主持七個階段、發牌、裁決、唱票、稽核)
- `ur reporter`   建立記錄者（戰況報表與結構稽核）
- `ur p1 … p9`    建立9位玩家

該角色需要知道的一切，會由這個命令載入。
僅需等待所有 agent 角色載入完畢後，接續在 god agent 中下「開始點名」即可開始進行遊戲。

## 回到 GOD，開始主持

```
開始點名           →  上帝點名其它 10 個 session，確認訊息通得到
進行遊戲模式設定    →  上帝問你四個參數，然後洗牌發牌
天黑請閉眼         →  第一夜開始
```

**每一句都等上帝引導你進行回應時再送出就好**，你不必記。

點名未達 11／11 上帝不會讓你繼續，故需確保所有人員都就續，再開始點名。

## 遊戲模式設定

| 參數 | 選項 | 預設 | 影響 |
|---|---|---|---|
| 你的角色 | 純觀戰／上帝視角觀戰／下場當玩家 | 上帝視角觀戰 | 上帝視角看得到全部底牌與夜間行動；純觀戰保留懸疑感，你不會知道任何人的底牌 |
| 推進節奏 | 每階段暫停／每天暫停／全自動 | 全自動到結局 | 決定上帝多久停下來等你 |
| 播報風格 | 中立紀實／沉浸敘事 | 沉浸敘事 | **只影響對你的敘述**，對玩家的訊息永遠中立 |

## 對局中你會看到什麼

**戰況要看 reporter 那個視窗。** 白天的發言由玩家自己落檔、由記錄者彙整並向你敘述，
上帝在發言輪只說程序（第幾位講完了、下一步是什麼）。

這樣安排是為了速度：發言不再逐字經過上帝，他一天要處理的文字量少掉一大半。
裁決、稽核、勝負判定與終局仍然由上帝向你說明。

記錄者會持續重建兩份儀表板，用瀏覽器直接開：

| 檔案 | 內容 |
|---|---|
| `game-state/report/index.html` | **公開版** —— 座位圖、時間軸、發言逐字稿、票型矩陣。零劇透 |
| `game-state/secret/report-spoiler.html` | **劇透版** —— 上列全部，再加底牌、每夜刀／查驗／用藥 |

**純觀戰就只開公開版。** 所有文字紀錄同步落在 `game-state/public/`，那個目錄不會劇透。

## 卡住的時候

**某個 session 重啟了** → 在那個 session 再說一次「你是p3」之類的話就好。上帝會補發它原本持有的資訊，不會給額外優勢。

**上帝忘了現在在哪一步** → 跟它說「繼續主持」。它會從狀態檔讀回天數、存活名單與下一步。

**逐字稿看起來少了幾個人** → 記錄者的併檔會落後一點，那不影響對局。
最新的發言原文一直都在 `game-state/public/speech-inbox/`。

**上一局還沒收就想開新的** → 說「歸檔」把它搬進 `game-archive/`。**不要手動刪 `game-state/`**，那會吃掉紀錄且不會有任何錯誤訊息。

**想中途改節奏或播報風格** → 直接跟上帝說，隨時可以改。

**上帝給玩家夾帶了戰術建議** → 那違反中立性契約，玩家可以當場指出。
