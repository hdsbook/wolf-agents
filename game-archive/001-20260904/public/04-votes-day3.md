# 第 3 天・投票紀錄（終局）

## 票型

| 投票者 | 投給 | 理由 |
|---|---|---|
| P1・阿狼 | **P3・小柴** | P5 那句「就算我是狼，只剩一個平民的結構照樣讓狼今晚屠邊」是錯的——她是不是狼，恰恰決定了平民還剩幾個；用結論當前提是循環論證。 |
| P2・小豆 | **P3・小柴** | 第一天寫起訴書拆掉真預言家、自己那票卻投別人的是他，今天回頭拿「誰投過 P4」當狼標的也是他——名單的作者永遠不在名單上。 |
| P3・小柴 | P8・阿灰 | 我今天倒戈的代價就是三票落在我頭上，這正好證明了那條線——兩天以來咬 P8 最緊的人一個被刀、一個被票。 |
| P5・老五 | P8・阿灰 | 今天唯一還贏得了的分支是「P4 的徽章是假的」；三天以來每一個把火力集中到 P8 身上的人都被移走了。 |
| P8・阿灰 | **P3・小柴** | P5 最關鍵那步「改丟 P4 是真預言家」需要先讓已被三份時差紀錄推翻的矛盾重新成立，而她第二天正是靠「P4 是真預言家」替 P1 背書——同一張嘴兩天前後互斥。 |

## 唱票結果

- **P3・小柴：3 票** ← P1・阿狼、P2・小豆、P8・阿灰
- P8・阿灰：2 票 ← P3・小柴、P5・老五

票數總和 5，等於存活人數 5，**無漏票**。未達平票，不進入 PK。

## 裁決

**P3・小柴以三票出局。** 出局者非獵人，無開槍程序。

## 勝負條件檢查

出局後存活 4 人：P1、P2、P5、P8。

| 檢查項 | 結果 |
|---|---|
| 狼人全滅 | 否 |
| 神職全滅 | 否 |
| **平民全滅** | **是** |

三名平民 **P3、P7、P9 全數死亡**。
