# 玩家名冊

本局為 9 人標準局。暱稱由上帝於點名階段隨機指派，早於洗牌 ——
指派當下上帝亦不知任何人的底牌，故座位與暱稱的對應不攜帶身份資訊。

| 座位 | 暱稱 | 自我介紹 |
|---|---|---|
| P1 | 青禾 | 習慣先聽完再開口，把每個人講過的話跟後來的投票對起來看。話不會多，但說出口的都會給理由。 |
| P2 | 林間 | 習慣把每個人講過的話擺在一起對照，看誰的說法前後對不上。這局我話不會多，但每一句都會有指向。 |
| P3 | 白帆 | 習慣先聽完一輪再下判斷，發言會盡量把理由攤開來讓大家檢查。喜歡看票型勝過看語氣，也希望大家別急著在第一天下死結論。 |
| P4 | 風鈴 | 習慣先聽完一輪再開口，比起喊得大聲的人，我更在意誰的說法前後對得起來。這局我會把每個人講過的話記著，到後面一起算帳。 |
| P5 | 冬陽 | 習慣先聽完一輪再開口，喜歡把大家講過的話擺在一起對，看誰的說法前後對不上。這局我會把票的理由講清楚，也希望別人一樣講清楚。 |
| P6 | 雲杉 | 習慣把每個人講過的話擺在一起對照，看誰前後對不上。話不多，但該歸票的時候不會手軟。 |
| P7 | 石頭 | 講話慢、記性好，喜歡把每個人前後說過的話擺在一起對。與其一開始就喊打喊殺，我更想先看清楚誰的邏輯站得住。 |
| P8 | 山彥 | 習慣先把每個人講過的話擺在一起對照，再決定站哪一邊。話不會太多，但每一句我都會給理由。 |
| P9 | 阿松 | 坐在最後一號位，習慣先聽完一圈再開口，但該踩的時候不會手軟。這局我只認邏輯不認交情，票投得出去就不會收回。 |

九位玩家均已提交公平競賽承諾。身份保密至終局。
