# 常用術語

這些是狼人殺的通用行話。**它們不是規則，是講話的簡稱** —— 用不用都可以，
但發言與爭議時若有人用了，全場應該理解成同一個意思。

收錄的每一個詞，在這個板子上都有對應的機制。**沒有機制的詞不收** ——
收了會讓玩家去嘗試一個上帝無法執行的動作。

標**本板注意**的那幾條，在這裡的意思與許多線下局不同，請照這裡的寫法理解。

## 查驗與「水」

| 名詞 | 意思 |
|---|---|
| 金水 | 預言家查驗結果為好人的玩家。**只代表非狼**，不代表是平民 —— 上帝告知的是陣營，不是身份 |
| 查殺 | 預言家查驗結果為狼人的玩家 |
| 鐵金水 | 由「確定是真預言家」發出的金水。**本板注意**：身份保密至終局，對局中無人能被確定，所以鐵金水永遠是判斷而非事實 |
| 狼金水 | 悍跳狼發出的金水，多半是他的狼隊友 |
| 認水 | 被發金水的人公開接受、承認這個查驗結果 |
| 銀水 | 夜間被刀、但被女巫解藥救活的玩家。**本板注意**：天亮只公布死者不公布死因，被救者自己不知道自己是銀水 |

## 跳身份與站邊

| 名詞 | 意思 |
|---|---|
| 悍跳 | 狼人冒充好人 —— 特別是冒充預言家 —— 跳出神職身份 |
| 對跳 | 兩人同時宣稱自己是預言家，其中**必有一狼** |
| 陪跳 | 狼隊安排第二個人一起跳同一個神職，把水攪渾、分散好人的判斷 |
| 站邊 | 表態相信哪一個跳預言家的人 |
| 退水 | 原本站邊某位預言家，後來改口不信了 |
| 反水 | 中途倒戈，把票或矛頭轉向原本站邊的那一邊 |
| 倒鉤 | 狼人不站自家悍跳的同伴，反而站真預言家那邊騙取信任，後期再反水 |

> 跳身份、對跳、倒鉤全部**合法** —— `conduct.md` 已寫明說謊與誤導是遊戲玩法。
> 每次發言的 `【宣告】` 欄就是你表態身份的地方，格式見 `/player-speak`。

## 夜晚的結果

| 名詞 | 意思 |
|---|---|
| 狼隊長 | 狼隊夜間的決策者。第 1 夜由上帝隨機指定，每夜提交接班順位，死後由順位接手。**他的決定直接成立**，不需要其他狼同意 |
| 夜間暗號 | 狼隊夜裡唯一的表達方式。**本板注意**：夜裡不能自由交談，只能用固定的暗號組合（`刀 P<n>`、`P<n> 像預言家`、`我悍跳`、`同意` 等），完整清單在 `flow.md` 階段 1 與 `/player-night-action`。不在表內的一律視為無效 |
| 自刀 | 狼人刀自己的隊友，用來混淆女巫或騙取解藥。目標沒有身份限制，合法 |
| 空刀 | 指狼隊當晚故意不砍人。**本板注意**：空刀不成立，每晚必定產生一個目標，這個戰術在這裡不存在 |
| 平安夜 | 沒有人死亡的夜晚。**本板注意**：既然空刀不成立，平安夜只有一種成因 —— 被刀者被解藥救回，**所以平安夜等於女巫的解藥已經用掉** |
| 毒殺 | 被女巫的毒藥毒死的人。被毒死的獵人**不能開槍** |
| 雙死 | 一夜死兩人。**本板注意**：可能是狼刀＋女巫毒，也可能是狼刀死了獵人、獵人開槍帶走一人 —— 看到雙死不能直接推論女巫用了毒 |
| 開槍／帶走 | 獵人被刀死或被投票出局時，翻牌帶走一位存活玩家 |

## 白天與投票

| 名詞 | 意思 |
|---|---|
| 踩 | 發言攻擊某人，指他是狼 |
| 小踩 | 輕微地點一下對方，說「他有點問題」但不歸票、留餘地 |
| 深踩／重踩 | 咬死對方是狼，明確歸票要推他 |
| 歸票／帶票 | 呼籲大家把票集中在某人身上 |
| 抗推 | 好人被誤票出局（「民抗推」＝平民被推掉） |
| 划水 | 發言沒有資訊量。**本板注意**：`/player-speak` 要求「400 字以內、一到三段、言之有物」，所以划水在這裡不只是風格，是違反發言規範。**湊字數同樣算划水** —— 上限是 400 字，不是要你寫到 400 字 |
| 前置位／後置位 | 發言順序在你前面／後面的人。**本板注意**：起始位與方向每天由上帝重新隨機決定，玩家無法選擇，所以這不是固定的位置關係 |
