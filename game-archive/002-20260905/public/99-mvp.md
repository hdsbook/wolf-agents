# 賽後 MVP 票選

## 結果

**MVP：P2・山彥（8 票）**　｜　P7・青禾（1 票，來自 P2 本人）

## 完整票型與理由

| 投票者 | MVP | 理由摘要 |
|---|---|---|
| P1・阿松 | P2 | 全場唯一真正驗中狼人；不洩漏查驗結果的隱晦指控手法教科書級；PK 命懸一線仍不亮牌，堅持邏輯對決。 |
| P3・白帆 | P2 | 唯一一次好人陣營資訊優勢成功轉化為票數；死前查驗未能傳出，但生前判斷與話術最乾淨。 |
| P4・冬陽 | P2 | 手法乾淨到完全沒洩漏查驗結果；若他沒被復仇刀死，或許能救回自己（P4）一命。 |
| P5・林間 | P2 | 生死壓力下仍守住不亮牌的紀律，比推理準確更難得；死亡本身是好人陣營最大的損失。 |
| P6・風鈴 | P2 | 承認自己就是被 P2 這手「起手式過於完整」精準拉下的對象，稱這是好人陣營整局唯一踩對節奏的一手。 |
| P7・青禾 | P2 | 身為對手狼人坦承 P2 是「威脅最大的一手」，未跳身份、未亮查驗結果就能靠邏輯揪出真狼。 |
| P8・湖心 | P2 | 幾乎憑一己之力扭轉整局；P2 的死才是真正決定屠邊的關鍵轉折。 |
| P9・雲杉 | P2 | 整局唯一一次神職資訊被成功轉化成票數的案例；PK 發言精準拆穿風鈴發言內容與姿態的落差。 |
| P2・山彥 | P7 | （無法投自己）指出 P7 第 2 天「命懸一線卻不打牌」的論證是狼隊逆轉戰局、成功保護自己與 P8 的關鍵一手。 |

## 最佳時刻（票選理由中反覆出現）

第 1 天，P2 用「起手式過於完整」這個完全不透露查驗結果的說法，精準把懷疑導向他驗到的真狼 P6；PK 命懸一線時，面對對方反問動機，他仍然只講邏輯層面、拒絕亮牌自保，最終以 4:3 把 P6 送出局——這是全場唯一一次好人陣營的資訊優勢被完整轉化為戰果。連對手陣營（P6、P7）都認證這是本局最具威脅、最漂亮的一手。也正因為這份精準與克制，讓狼隊判定他是頭號威脅，第 2 夜就展開精準復仇——他的死亡，成了決定屠邊勝負的關鍵轉折。
